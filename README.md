# CHATTER

CHATTER is a lightweight, dark real-time web chat room built for fast conversations without account login. It supports shared rooms, presence indicators, live typing status, file sharing, audio/video calls, screen sharing, emoji reactions, mobile layouts, and a creator attribution area for Emmanuel Kingsley.

## Live website

**[Open CHATTER](https://chatterapp-tzpsxxid.manus.space/)**

## Run locally

```bash
pnpm install
pnpm dev
```

The application uses the full-stack React, tRPC, Express, Drizzle, and MySQL template. Copy the required runtime environment variables into a local `.env` file before starting the server if you want database-backed rooms, messages, presence, uploads, and call signaling.

## Validation

```bash
pnpm test -- --run
pnpm check
pnpm build
```
